# North Pole OS — deployment handoff

Upload the three original binary assets into this directory, using these exact case-sensitive filenames:

- `North-Pole-OS-Fullscreen.apk` — original Android installer
- `preview.png` — wallpaper artwork
- `icon.png` — application icon

The root landing page already contains the responsive Live Wallpapers section and installation instructions. Its download button automatically activates when the APK is served successfully by GitHub Pages. No HTML edits are required. The artwork and icon appear automatically once uploaded.

After committing to main, wait for Pages deployment, open https://lab137-dev.github.io/#wallpapers, confirm the artwork and icon load, and download the APK. Compare downloaded bytes or SHA-256 with the original. Do not publish the separate unbranded Christmas wallpaper as part of this collection.
